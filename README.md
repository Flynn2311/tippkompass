# Tippkompass

Sporttipps für Fussball und Eishockey: sichere, mittlere und riskante Tipps, Kombis, Spielgeld und Tipprunden mit Kollegen.

- `index.html`, `app.js`: die App
- `firebase.js`: Anmeldung und Online-Spielstand (Firebase)
- `data.json`: Spiele, Quoten und Resultate (wird automatisch aktualisiert)
- `firestore.rules`: Sicherheitsregeln für die Datenbank

In der App wird kein echtes Geld gesetzt. Nicht mit Swisslos verbunden.
